# Projeye Katkıda Bulunma 🤝

Katkılarınızı bekliyoruz! Lütfen aşağıdaki adımları izleyin:

1. Depoyu **Fork** edin.
2. Bir özellik (feature) dalı oluşturun: `git checkout -b feature/harika-ozellik`.
3. Değişikliklerinizi commit edin: `git commit -m 'feat: harika özellik eklendi'`.
4. Dalı projenize push edin: `git push origin feature/harika-ozellik`.
5. Bir **Pull Request** açın.

## Kodlama Standartları

* **Python:** PEP 8 standartlarını takip edin.
* **JavaScript:** ES6+ özelliklerini kullanın ve Prettier ile formatlayın.
* **Commit Mesajları:** Conventional commits yapısını kullanın (örneğin: `feat: add user login`, `fix: button color`).
